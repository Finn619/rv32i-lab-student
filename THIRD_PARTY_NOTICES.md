## RISC-V architectural tests (BSD-3-Clause / Apache-2.0)

From https://github.com/riscv/riscv-arch-test, tag 3.10.0, whose code is
licensed under BSD-3-Clause or Apache-2.0 (see `COPYING.BSD` and
`COPYING.APACHE` in that repository):

* `arch-test/env_sail/model_test.h` and `arch-test/env_sail/link.ld` are
  copied from `riscof-plugins/rv32/sail_cSim/env/`.
* `arch-test/env_soc/model_test.h` follows the structure of the same file.
* `arch-test/references/*.reference_output` were generated by running the
  suite's `rv32i_m/I` tests on the Sail RISC-V model
  (https://github.com/riscv/sail-riscv, release 0.16).

The test sources themselves are not included; `arch-test/archtest.py fetch`
downloads them.
